# Gemini CLI / Google

Instale em `~/.gemini/skills/humanizar-natural-ptbr` ou `.gemini/skills/humanizar-natural-ptbr`. Verifique o reconhecimento com `/skills list`; na ativação o Gemini CLI pode pedir confirmação. Se a pasta de trabalho não for confiável, a skill de projeto pode não estar disponível até que o workspace seja confiável.

O pacote também traz `gemini-extension.json` e um `GEMINI.md` curto para uso como extensão quando a ferramenta aceitar a estrutura da raiz. O `GEMINI.md` não replica a skill: apenas aponta para sua existência. Não há comandos extras nem acesso a dados externos.

Fonte: https://github.com/google-gemini/gemini-cli/blob/main/docs/cli/skills.md
